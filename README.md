    - 1️⃣ What is the difference between var, let, and const?
    - 2️⃣ What is the spread operator (...)?
    - 3️⃣ What is the difference between map(), filter(), and forEach()?
    - 4️⃣ What is an arrow function?
    - 5️⃣ What are template literals?

1. Ans: var is function scoped, can be redeclared, and hoisted as undefined. let is block scoped, can reassigned but not redeclared and const is also block scoped but can't neither be reassigned nor redeclared.

2. Ans: The spread operator expands an iterable into individual elements.

3. Ans: map() transforms each element and returns a new array. filter() keeps elements that pass the test and return a new array. And forEach() runs a function on each element but does not return anything.

4. Ans: An arrow function is a shorter way to write a function. Instead of writing "function", we use "=>" .

5. Ans: Template literals use backticks instead of quotes, letting us embed expressions and write multiline strings cleanly.
